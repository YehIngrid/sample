AppModal 使用說明

站內自製彈窗元件，取代 SweetAlert2。import { AppModal } from '../default/app-modal.js';，記得同時連結 app-modal.css。呼叫方式跟 Swal.fire(opts) 盡量對齊，回傳 Promise<{isConfirmed, isDismissed, value}>。

基本欄位

欄位型別說明
iconstringsuccess / error / warning / info / question，不填就不顯示圖示
titlestring標題，會自動跳脫 HTML
textstring內文純文字，會自動跳脫 HTML
htmlstring內文原始 HTML（跟 text 擇一，優先用 html）

按鈕

欄位型別說明
showConfirmButtonboolean預設 true；設 false 可做成無按鈕的純提示／toast
confirmButtonTextstring預設「確定」
showCancelButtonboolean預設 false
cancelButtonTextstring預設「取消」
allowOutsideClickboolean預設 true；設 false 點背景不會關閉

輸入欄位

欄位型別說明
inputstringtext 或 checkbox
inputPlaceholderstringtext 時是 placeholder；checkbox 時是選項文字
inputValuestring / boolean預設值（checkbox 用 boolean）

確認後 res.value 會是輸入的文字，或 checkbox 的 true/false。

Toast（右上角提示，自動消失）

欄位型別說明
toastboolean設 true 啟用 toast 模式（無遮罩、無按鈕、右上角小卡）
timernumber（ms）幾毫秒後自動關閉；一般 alert 也能用，時間到自動視為取消關閉

圖片燈箱

欄位型別說明
imageUrlstring設定後整個彈窗變成深色圖片檢視器，右上角一顆關閉鈕，其餘欄位（title/text/按鈕）都會被忽略
imageAltstring圖片 alt 文字

進階

欄位型別說明
didOpen(dialogEl) => void彈窗顯示動畫跑完後呼叫，參數是彈窗的 DOM 節點，適合在 html 裡放了互動元素、需要另外綁事件時使用
willClose(dialogEl) => void關閉前呼叫（例如清掉 didOpen 裡設的 setInterval）
customClass{popup, title, htmlContainer, container}個別加 class，比照 SweetAlert2 的用法
widthnumber / string覆寫預設的最大寬度（例如 520 或 '600px'），圖片燈箱模式無效
allowEscapeKeyboolean預設 true；設 false 按 Esc 不會關閉

AppModal.close()：關閉目前開著、沒有按鈕的彈窗（例如先 fire() 一個「處理中」提示，API 回來後呼叫這個關掉，用法對齊 Swal.close()）。

不支援 preConfirm / inputValidator（需要攔截確認、顯示驗證錯誤訊息的複雜表單）——這類彈窗目前仍維持用 SweetAlert2，樣式已另外調整成跟這個元件一致。
